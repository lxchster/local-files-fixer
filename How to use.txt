LOCAL FILES FIXER
=================

Finds and fixes the hidden problems in .mp3 / .m4a files that make Spotify "Local files"
grey out, or fail to match between your PC, Mac and phone.

FIRST TIME?  Nothing needs installing. On a Mac, unzip the Mac download and open
  "Local Files Toolkit.app" (first time only: right-click it > Open > Open). On Windows,
  double-click "Local Files Toolkit.bat".
  If something won't open or install, double-click "Setup.bat" (Windows) or "Setup.command"
  (Mac). It checks your computer, installs anything that is missing (only needed to run the app
  from source), and lists in plain words any Windows / macOS setting or permission that is in
  the way - for example a blocked install, a "Windows protected your PC" box, or a network set
  to Public that stops "Send files" reaching your phone. Safe to run as many times as you like.

TWO VERSIONS (they find and fix exactly the same things)
  NEW LOOK (recommended)   Double-click "Local Files Toolkit.bat" (Windows) or
                           "Local Files Toolkit.command" (Mac). If a ready-made app is sitting
                           in electron-app\dist, that opens straight away with nothing to
                           install. Otherwise it installs what it needs the first time (see below).
                           Rounded, Spotify-style window. Lives in the "electron-app" folder.
  CLASSIC                  Run "python local_files_fixer.py" (plain Python window)

HOW TO USE
  1. Open the app.
  2. Click "Choose folder..." (or drag a folder onto the window) and pick your music folder.
     It scans straight away, including sub-folders.
  3. Look at the list. Leave "Back up originals" ticked.
  4. Click "Fix everything ticked". (Or click some rows to select them, then "Fix selected rows".)
  5. Restart Spotify. If you use the same files on another device, copy the fixed files there too,
     then remove and re-add the affected songs in your playlists.

WHAT IT FIXES
  MP3 length header   A hidden header frame that different apps count differently, so they
                      disagree on a song's length by a second (or much more). It is removed;
                      no audio changes. Variable-bitrate MP3s are left alone.
  M4A gapless tag     A tag that says the song is a different length than it really is.
                      Only three numbers inside the tag are corrected.
  Mac leftovers       .DS_Store files, "__MACOSX" folders and "._" companion files.
  Minor tidy-up       (off by default) a gapless tag that is off by a tiny amount.

SAFETY
  - Every change is written to a temporary file, checked, then swapped in.
  - With "Back up originals" ticked, the original of every changed file is saved in a folder next to
    the one you chose, named "<folder> - backup <date and time>". Copy files back from there to undo.
  - Files that don't look exactly as expected are skipped and left untouched.
  - Close Spotify first if it tells you a file couldn't be written.

ON A MAC
  Open "Local Files Toolkit.app" from the Mac download (works on Intel and Apple Silicon, needs no
  Python, Node.js or Terminal). Because the app isn't notarized by Apple, the very first time use
  right-click > Open > Open. (macOS 15 and later: open it once, then System Settings > Privacy &
  Security > Open Anyway.) If you have this whole folder instead, double-click
  "Local Files Toolkit.command" - it clears the "damaged" flag for you and opens the app.

TAG SONGS - NOTHING TO INSTALL
  Tag songs is built into the app. No Python, no extra packages.

BUILDING A READY-MADE APP (so nobody needs Node.js at all)
  Mac: on GitHub, Actions tab > "Build Mac app" > Run workflow. Download the zip it makes.
  Windows (or Mac, from any computer with Node.js):
      cd electron-app
      npm install
      npm run package        (Windows build)
      npm run package:mac    (Mac build)
  Hand the result to anyone else - nothing to install on their end.

COMMAND LINE (optional, no window)
  node electron-app/src/cli.js "D:\Music"                 just list the problems
  node electron-app/src/cli.js "D:\Music" --fix           fix them (with backup)
  add --no-backup to skip backups, --minor to include the minor tidy-up
